# For Dulee, from Chanel

A romantic interactive proposal website made for GitHub Pages.

## How to personalize it

1. Add or replace photos as `assets/photos/photo-01.jpg` through `assets/photos/photo-12.jpg`.
2. Open `index.html` and replace the personal message placeholder.
3. Push the folder to a GitHub repo.
4. In GitHub, go to Settings > Pages and publish from the main branch.

The user flow is: Start Button -> Notes -> Pictures -> Personal Message -> The Question -> Date Planner.

The final date planner asks two questions, then includes share/copy buttons so Dulee can send Chanel the result.
For automatic result collection, connect a form service or backend before publishing.
